# QPUC Club — téléchargement

Téléchargez **QPUC_Club.zip** dans la section [Releases](../../releases/latest).

1. Décompressez l’archive.
2. Ouvrez le dossier `QPUC_Club`.
3. Lancez `QPUC_Club.exe`.

Python n’est pas nécessaire. Le fichier `LISEZ-MOI.txt` dans l’archive
explique le premier lancement sous Windows et la connexion des téléphones.

Ce dépôt distribue uniquement le logiciel compilé et son guide d’utilisation.
